# Ignore for Plausible (Arbeitstitel)

Browser-Extension, die `localStorage.plausible_ignore = "true"` setzt. Damit zählt Plausible deine eigenen Besuche nicht mehr. Pro Site oder global, mit Debug-Ansicht. Ziel: Release im Chrome Web Store und bei Firefox Add-ons.

Stack: Manifest V3, TypeScript, Vite, Svelte 5, pnpm.
